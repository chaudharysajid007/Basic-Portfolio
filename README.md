🌐 Basic Portfolio

«✨ A simple portfolio website built from the ground up using basic HTML5 tags and fundamental web development concepts.»

Welcome to my Basic Portfolio! 👋

This project is a beginner-friendly portfolio website created to practice and demonstrate the fundamentals of HTML5. The website is intentionally kept simple so that the core structure and purpose of HTML elements can be clearly understood.

---

🎯 About This Project

This portfolio was created as part of my journey into Web Development. 🚀

The main purpose of this project is to understand how different HTML elements work together to create a complete multi-page website.

Instead of using frameworks or complicated technologies, this project focuses on the fundamentals of HTML.

«🧱 Start with the basics. Build the foundation. Then build bigger things.»

🎓 Learning Goal

The goal of this project is not to create a highly complex website.

The goal is to understand the building blocks of the web. 🧱🌐

Before moving toward CSS, JavaScript, React, and other technologies, understanding HTML provides the foundation needed to build better websites.
